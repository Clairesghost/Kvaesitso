# Start here

You do not need to know how to program. You need about 10 minutes to start.

## Step 1: get ready (once)
1. On your computer, install Claude Code from claude.com/claude-code and sign in. Make a free account at github.com if you have none.
2. Make a new empty folder with a short name and no spaces, for example `C:\launcher` (Windows) or `~/launcher` (Mac). Unzip this kit into it, so that you see `START-HERE.md` and a `.claude` folder inside.
3. Open Claude Code in that folder (in a terminal: type `claude`; in the desktop app: choose the folder).

## Step 2: paste this first message into Claude Code
```
Hello. I want to make my own phone home screen (a launcher) with the Launcher Studio kit in this folder. I am not technical. Please read README.md and then act as the kit-guide agent (.claude/agents/kit-guide.md): set up the project with me one small step at a time, then interview me with multiple-choice questions about how I want my phone to look and work. Never push anything to GitHub without my clear yes. Tell me in plain words what I must do, in numbered steps.
```

## Step 3: answer the questions
- Claude asks up to four multiple-choice questions at a time. Pick one, or write "you choose" or your own idea.
- You can stop any time. Next time open Claude Code in the same folder and say: "Continue my launcher project (kit-guide)."
- Nothing is sent to GitHub and nothing is built until you say yes.

## What you will be asked to do on the phone
Install a file (APK), switch on "Install unknown apps" for your browser once, and try a short list of checks. Claude writes the exact steps each time.

## If you get stuck
Say "I am stuck" and what you see. Claude will explain in simpler words. You can also read `README.md` and `playbook/ci-and-signing.md`.

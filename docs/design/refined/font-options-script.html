Vintage script heading options

You pointed at the bold "Vintage" lettering in your screenshot: a thick, swooping 1950s brush script. That exact font is a paid design, so these are free Google fonts in the same family. Each is on the tan placard, with the body text kept in Franklin.

Tip: script is hard to read in all capitals or at small sizes. I'd use it for the big words only (event title, date number, ALERTS) and keep the rest in Franklin.
